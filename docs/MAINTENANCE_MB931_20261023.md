Base: `snap_mediabot_v3_teuk_20261023_173446.zip`,
VERSION `3.6dev-20261023_151818`.

Change the badge from `reddit` to `[reddit]`, retaining IRC foreground 01,
background 07 and an immediate reset. Keep the bold title, theme-neutral body
and one-line 400-byte UTF-8 limit.

Extend the existing Reddit provider with an optional read of the static public
iframe generated by the official embed widget, after obtaining valid basic
metadata. Bind the iframe wrapper, structured entity and event permalink to
the exact post/comment. Read only counters bound to that entity. Add available
score, comments or comment replies, UTC publication date, content type and
labels. Do not invent hidden counts or use embed-generation timestamps.

For a comment, use its own prose when provided; preserve explicit parent-title
context for code/art-only or quoted-only bodies. Keep oEmbed attribution rather
than harvesting user links from the quoted content or a surrounding header.
An explicitly removed body invalidates stale content. A failed detail request
preserves valid basic metadata, including on HTTP errors, malformed HTML and
absolute detail timeout. A detail-source 429 preserves the basic preview while
still respecting Retry-After. There is no redirect retry for enrichment.

Keep AsyncWorker and IRC delivery guards unchanged. Optional enrichment takes
at most six seconds and is skipped once its collection budget is exhausted;
it cannot consume an external caller's existing alarm. All work stays in the
existing child process. No provider/router, chanset, schema, migration, private
configuration, VERSION or activation policy change is included.

Extend the existing isolated MB930 case and fixture with nine grouped detail
scenarios (41 total, plus the isolated-process assertion). No case is added or
retired. Exercise exact identity, parent/foreign counters, date provenance,
hidden fields, code/quotes/deletion, HTTP errors/redirects/429, absolute deadline,
caller alarm preservation, hostile fields, singular/plural, bracket bytes and
the 400-byte budget. The native IO::Async success scenario now runs the real
two-source parser path in a child, without reaching HTTP in the parent.

See `docs/REDDIT_PREVIEWS.md` for behaviour and the existing read-only checker.
Package qualification records public live probes, reference/candidate complete
suites, mutations and guarded installer rehearsals. The complete unfiltered
server suite and both audits remain mandatory.
